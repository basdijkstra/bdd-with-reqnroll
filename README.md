# Behavior-Driven Development with Reqnroll

This repository contains all the code supporting the free, self-paced [Test Automation University](https://testautomationu.applitools.com/) course on Behavior-Driven Development with Reqnroll.

[Sign up here](https://testautomationu.applitools.com/bdd-with-reqnroll/) and learn more about BDD and how to use Reqnroll to support your software development and testing efforts.

If you want to run the example code in this repository on your own machine, you will need [.NET 10](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) installed, as well as a recent Chrome browser for the tests you see in Chapter 10.
